OUR HISTORY

熊本で、
長く続けてきたこと。

1948 → NOW

時代や街が変わっても、 建物を守る仕事はなくなりません。 オーファスは1948年の創業から、 熊本のさまざまな建物と人を支えてきました。

1948

創業

熊本で事業をスタート。 建物を支える仕事の歴史が始まりました。

1970s

サービス領域を拡大

清掃だけでなく、建物を総合的に支える サービスへと事業を広げていきました。

2000s

さまざまな施設へ

オフィス、公共施設、病院、商業施設など、 多様な建物の管理を担う会社へ。

NOW

これからのオーファスへ

建物と人を未来へつなぐ会社として、 新しい仲間とともに次の時代へ進みます。

昔から変わらないこと。 時代に合わせて変わってきたこと。 その両方を大切にしています。

WORK

どんな仕事が、
あるんだろう。

仕事の名前だけでは、 なかなかイメージできないもの。 オーファスにはさまざまな働き方があります。

WORK / CLEANING
WORK 01

清掃

オフィスや施設を、 気持ちよく使える空間に整える仕事です。 専門的な作業もありますが、 未経験から始めるスタッフも多くいます。

未経験OK 短時間勤務あり 幅広い年代
WORK / SECURITY
WORK 02

警備

施設を利用する人の安全や安心を守ります。 立哨だけでなく、 座哨や巡回など現場によって働き方もさまざまです。

WORK 03

電気・空調・給排水など、 建物の設備が問題なく動いているかを確認し、 安全な環境を保ちます。
